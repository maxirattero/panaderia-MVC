# Instrucciones persistentes del proyecto

- Al completar cambios en este proyecto, verificarlos y desplegarlos en producción, salvo que el usuario pida explícitamente lo contrario. Esta autorización incluye el commit y push necesarios para el despliegue habitual en Railway.
- Comprobar el resultado del despliegue e informar si quedó pendiente o falló; no presentar un push como un despliegue verificado.
- Consultar `CLAUDE.md` para las convenciones y la arquitectura del proyecto.
